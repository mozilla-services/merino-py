# Merino API documentation

This page describes the API endpoints available on Merino.

The autogenerated API documentation exists [here](https://merino.services.mozilla.com/docs).

The API documentation covers every endpoint Merino offers. Merino runs as several workloads, each
serving part of the API. In production, HTTP route rules on the gateway send each request to the
workload that serves it. So the documentation shows what is available to clients at
`merino.services.mozilla.com`, not what each individual pod serves. The schema behind it is
generated at build time and committed at `apps/merino/merino/data/openapi.json`.
